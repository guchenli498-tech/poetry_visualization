# 中华诗词山河文化地图可视化系统

一个基于Python的数据可视化项目，用于分析和展示中华古诗词中的地理意象分布、情感趋势以及相关诗句。

## 📋 项目简介

本项目通过分析全唐诗、宋词等古诗词数据，提取其中的地理实体（山川、河流、城市等），并进行情感分析、关键词提取等处理，最终生成交互式的可视化仪表板。系统支持：

- 🗺️ 地理热度地图：展示诗词中提及的地理位置分布
- 📊 情感分析：分析不同地理意象的情感倾向
- 📈 朝代统计：统计各朝代对地理意象的提及情况
- ☁️ 关键词云：展示与地理意象相关的关键词
- 🔗 诗人网络：展示诗人与地理意象的关联关系
- 📝 诗句展示：显示包含特定地理意象的诗句，支持分页浏览

## 🎨 作品主题背景

中华古诗词是中华文化的瑰宝，其中蕴含着丰富的地理意象。从"大漠孤烟直，长河落日圆"到"会当凌绝顶，一览众山小"，从"烟花三月下扬州"到"姑苏城外寒山寺"，诗人们用文字描绘了祖国的大好河山，也记录下了他们对不同地域的情感与记忆。

本项目旨在通过数据可视化的方式，探索古诗词中地理意象的分布规律、情感特征和文化内涵，揭示：
- **地理分布特征**：哪些山川河流、城市关隘在诗词中出现频率最高？
- **情感倾向分析**：不同地理意象在诗词中承载了怎样的情感色彩？
- **朝代演变趋势**：不同朝代对地理意象的关注点和情感表达有何差异？
- **诗人地理轨迹**：诗人如何通过诗词记录自己的行迹，形成独特的"地理记忆"？
- **文化意象关联**：地理意象与哪些关键词、主题紧密相关？

通过这种跨学科的研究方法，我们希望为传统文化研究提供新的视角，让古诗词中的"山河记忆"以更直观、更生动的方式呈现。

## 📊 数据说明

### 数据来源

本项目使用的诗词数据主要来源于开源项目 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，这是一个包含最全中文诗歌古典文集的开源数据库：

- **全唐诗**：包含约5.5万首唐诗，涵盖唐代近1.4万位诗人的作品
- **全宋词**：包含约2.1万首宋词，涵盖两宋时期1.5千位词人的作品
- **其他文集**：包括五代诗词、元曲、诗经、楚辞等古典文集

数据格式为JSON，每个诗词条目包含以下字段：
- `title`: 诗词标题
- `author`: 作者姓名
- `content`: 诗词内容（可能是字符串或数组）
- `dynasty`: 朝代信息（部分数据包含）

### 数据描述

#### 1. 诗词原始数据
- **数据量**：默认分析50,000首诗词（可配置）
- **数据格式**：JSON格式，每个文件可能包含单条或多条记录
- **数据分布**：主要来自全唐诗和宋词两个数据集
- **数据质量**：数据来源于互联网公开资源，经过社区维护和校验

#### 2. 地理实体词典 (`data/geo_entities.json`)
- **内容**：包含900+个地理实体的标准名称、类型、别名和现代对应名称
- **类型分类**：城市、山脉、河流、湖泊、关隘、地区等
- **别名支持**：每个地理实体支持多个历史别名（如"长安"的别名包括"京兆"、"镐京"、"大兴城"等）
- **示例**：
  ```json
  {
    "长安": {
      "type": "城市",
      "aliases": ["京兆", "镐京", "大兴城", "西京", "上都"],
      "modern_name": "陕西西安"
    }
  }
  ```

#### 3. 地理坐标数据 (`data/geo_coordinates.json`)
- **内容**：地理实体的经纬度坐标，用于地图可视化
- **坐标系统**：WGS84坐标系（GPS标准）
- **覆盖范围**：涵盖主要城市、名山大川、重要关隘等
- **数据来源**：结合历史地理资料和现代地图数据

#### 4. 诗人资料数据 (`data/author_profiles.json`)
- **内容**：诗人的籍贯、主要行迹等背景信息
- **用途**：用于构建诗人地理轨迹和关联分析

### 数据处理流程

#### 步骤1：数据加载与清洗
1. **文件遍历**：递归遍历 `chinese-poetry/` 目录下的所有JSON文件
2. **格式统一**：处理不同格式的诗词内容字段（`content`、`text`、`paragraphs`、`poem`）
3. **朝代推断**：根据文件路径和元数据推断朝代信息
4. **数据过滤**：过滤掉内容过短或格式异常的数据

#### 步骤2：地理实体提取
1. **词典匹配**：使用地理实体词典进行精确匹配（包括别名）
2. **正则补充**：使用正则表达式匹配常见地名模式（如"XX山"、"XX江"等）
3. **分词识别**：使用jieba分词识别地名（词性标注为`ns`）
4. **名称标准化**：将别名统一映射到标准名称
5. **过滤处理**：排除抽象概念和通用词汇（如"江山"、"天下"等）

#### 步骤3：情感分析
1. **基础情感得分**：使用SnowNLP计算文本的基础情感得分（0-1之间）
2. **多维度分析**：结合情感词典进行多维度情感分析（豪放、婉约、忧愁、积极、消极等）
3. **情感分类**：将得分映射到5个情感类别（非常正面、中性偏正面、中性、中性偏负面、非常负面）
4. **主题识别**：识别诗词主题（战争、自然、季节、情感、历史等）

#### 步骤4：关键词提取
1. **文本聚合**：将包含同一地理实体的所有诗词文本聚合
2. **关键词提取**：使用jieba的TF-IDF算法提取关键词（Top 30）
3. **权重计算**：计算每个关键词的TF-IDF权重

#### 步骤5：诗句片段提取
1. **句子分割**：按标点符号（，。！？；\n）分割诗词内容
2. **地名匹配**：在句子中查找地理实体（支持别名匹配）
3. **片段提取**：提取包含地名的完整句子
4. **去重处理**：去除重复的诗句片段

#### 步骤6：数据聚合与统计
1. **地理统计**：按地理实体聚合出现次数、情感分布、朝代分布等
2. **诗人轨迹**：构建诗人与地理实体的关联关系
3. **坐标匹配**：将地理实体与坐标数据关联
4. **数据导出**：将处理结果导出为JSON格式

### 输出数据说明

#### 1. `geo_stats.json` - 地理统计结果
包含每个地理实体的详细统计信息：
- `名称`、`类型`、`现代对应`：基本信息
- `总出现次数`：在诗词中出现的总次数
- `情感统计`：各情感类别的分布
- `平均情感得分`：情感得分的平均值
- `出现诗人`：提及该地理实体的诗人列表
- `坐标`：经纬度坐标
- `朝代统计`：各朝代的出现次数和情感分布

#### 2. `sentiment_trend.json` - 情感趋势数据
按朝代统计每个地理实体的情感趋势，用于分析不同朝代对同一地理意象的情感表达差异。

#### 3. `keyword_clouds.json` - 关键词云数据
每个地理实体对应的关键词及其权重，用于生成词云图。

#### 4. `poet_paths.json` - 诗人轨迹数据
记录诗人与地理实体的关联关系，包括：
- 诗人的籍贯信息
- 诗歌中出现的地理位置统计
- 地理位置的出现顺序（用于轨迹分析）

#### 5. `poetry_quotes_by_geo.json` - 诗句数据
每个地理实体对应的诗句片段列表，格式为：
```json
{
  "地理实体名称": [
    {
      "诗句": "包含地名的诗句",
      "诗人": "作者姓名",
      "诗名": "诗词标题"
    }
  ]
}
```

## 🛠️ 可视化工具与技术栈

### 可视化工具

本项目主要使用 **PyECharts** 作为可视化工具，这是一个基于ECharts的Python可视化库，具有以下优势：

- **丰富的图表类型**：支持地图、柱状图、饼图、词云、关系图等多种图表
- **交互性强**：支持缩放、拖拽、点击等交互操作
- **主题定制**：支持多种主题（本项目使用暗色主题）
- **易于集成**：生成的图表可以轻松嵌入HTML页面

### 使用的图表类型

1. **地理散点图 (Geo - Effect Scatter)**
   - 用于展示地理实体在中国地图上的分布
   - 点的大小反映出现频率
   - 支持点击交互，查看详细信息

2. **柱状图 (Bar)**
   - 展示各朝代对地理意象的提及次数
   - 横向柱状图，便于比较

3. **饼图 (Pie - Rose Type)**
   - 展示特定地理意象的情感分布
   - 使用玫瑰图样式，更美观

4. **词云图 (WordCloud)**
   - 展示与地理意象相关的关键词
   - 词的大小反映TF-IDF权重

5. **关系图 (Graph)**
   - 展示诗人与地理实体的关联网络
   - 圆形布局，中心为地理实体，周围为相关诗人

6. **折线图 (Line)**
   - 可用于展示情感趋势随时间的变化（预留功能）

## 📈 作品解读

### 可视化内容

本项目实现了6个核心可视化模块，从不同维度展现古诗词中的地理意象：

#### 1. 地理热度地图 🗺️
- **呈现内容**：在中国地图上以散点图形式展示所有地理实体的分布
- **视觉特征**：
  - 点的位置：地理实体的实际地理位置（经纬度）
  - 点的大小：与出现频率成正比（出现次数越多，点越大）
  - 颜色映射：通过颜色深浅反映热度（热力图效果）
  - 交互功能：点击地图上的点可查看该地理实体的详细信息

#### 2. 各朝代地理意象提及次数柱状图 📊
- **呈现内容**：横向柱状图展示不同朝代对地理意象的总体提及次数
- **数据维度**：按朝代（唐、宋、元等）统计所有地理意象的出现次数
- **分析价值**：揭示不同朝代对地理意象的关注程度差异

#### 3. 情感分布饼图 🥧
- **呈现内容**：玫瑰图展示特定地理意象在诗词中的情感分布
- **情感分类**：非常正面、中性偏正面、中性、中性偏负面、非常负面
- **交互联动**：随地图点击或热门榜选择动态更新
- **分析价值**：揭示不同地理意象在诗词中承载的情感色彩

#### 4. 关键词云图 ☁️
- **呈现内容**：词云图展示与特定地理意象相关的关键词
- **词的大小**：反映关键词的TF-IDF权重（权重越大，词越大）
- **数据来源**：从包含该地理意象的所有诗词文本中提取
- **分析价值**：揭示地理意象的文化内涵和主题关联

#### 5. 诗人共吟网络图 🔗
- **呈现内容**：关系图展示与特定地理意象相关的诗人网络
- **布局方式**：中心为地理实体，周围为相关诗人
- **节点大小**：反映诗人提及该地理意象的次数
- **连线粗细**：反映关联强度
- **分析价值**：揭示哪些诗人对特定地理意象有共同关注

#### 6. 诗句展示列表 📝
- **呈现内容**：分页展示包含特定地理意象的诗句片段
- **显示格式**：诗句 - 诗人《诗名》
- **分页功能**：每页10首，左右分栏显示
- **数据来源**：从原始诗词中提取包含地名的完整句子

#### 7. 热门山河意象榜 🏆
- **呈现内容**：展示出现频率最高的8个山河意象
- **筛选标准**：必须包含山河相关关键词（山、江、河、湖等）
- **交互功能**：点击可切换查看该地理意象的详细信息

### 呈现的内容与发现

#### 地理分布特征
1. **热门地理意象**：
   - 名山大川（如泰山、华山、长江、黄河）出现频率最高
   - 历史文化名城（如长安、洛阳、扬州、杭州）备受关注
   - 边塞关隘（如玉门关、雁门关）在边塞诗中频繁出现

2. **地域分布规律**：
   - 中原地区（陕西、河南）的地理意象出现频率最高
   - 江南地区（江苏、浙江）在宋词中提及较多
   - 边塞地区（甘肃、新疆）在边塞诗中占据重要地位

#### 情感倾向分析
1. **正面情感意象**：
   - 名山大川多与豪迈、壮美情感相关
   - 江南水乡多与婉约、柔美情感相关
   - 历史名城多与怀古、思乡情感相关

2. **负面情感意象**：
   - 边塞关隘常与离别、思乡的愁苦情感相关
   - 某些地理意象在不同朝代的情感色彩有所变化

#### 朝代演变趋势
1. **唐代特点**：
   - 更关注边塞地理（反映唐代边塞诗的繁荣）
   - 情感表达更加豪放、激昂
   - 对名山大川的描写更加壮阔

2. **宋代特点**：
   - 更关注江南地区（反映宋代经济重心南移）
   - 情感表达更加细腻、婉约
   - 对城市生活的描写更加丰富

#### 诗人地理轨迹
1. **行迹记录**：
   - 通过诗词可以追踪诗人的行迹轨迹
   - 不同诗人对同一地理意象的关注程度不同
   - 某些诗人形成了独特的地理偏好

2. **文化网络**：
   - 多个诗人对同一地理意象的关注形成文化网络
   - 揭示了地理意象在文化传播中的重要性

### 得到的结论

#### 1. 文化地理学视角
- **地理意象是文化记忆的载体**：古诗词中的地理意象不仅是地理位置的描述，更是文化记忆和情感表达的载体
- **地域文化特色鲜明**：不同地域在诗词中形成了独特的文化意象（如"江南"代表柔美，"边塞"代表豪迈）

#### 2. 文学史视角
- **朝代特色明显**：不同朝代对地理意象的关注点和表达方式有明显差异，反映了时代背景和文学风格的变化
- **题材与地理的关联**：边塞诗、山水诗、田园诗等不同题材与特定地理意象紧密相关

#### 3. 数据可视化价值
- **直观呈现文化现象**：通过可视化，可以直观地看到哪些地理意象在诗词中最受关注
- **发现隐藏规律**：通过数据分析，可以发现一些通过传统研究方法难以发现的规律和趋势
- **跨学科研究**：将文学研究与数据科学结合，为传统文化研究提供了新的视角和方法

#### 4. 技术应用价值
- **自然语言处理的应用**：展示了NLP技术在传统文化研究中的应用潜力
- **交互式可视化**：通过交互式可视化，用户可以主动探索数据，发现感兴趣的内容
- **数据驱动研究**：为基于大数据的文学研究提供了实践案例
